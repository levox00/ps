# Publication policy for Petals Hub scripts

- Treat human-readable project Lua/Luau code, including loaders and UI scripts, as private working source. Never upload or commit it to a public repository, public paste, script host or other public endpoint. Keep source, debug builds, tests and deobfuscated output local or in an explicitly authorized private location.
- Before publishing any executable project Lua/Luau file or loadstring, obfuscate the complete delivered script with the locally available Hercules fork. Use the user-requested options; if none were specified, use Heavy. Do not publish if the obfuscator fails or compatibility has not been checked; explain the blocker.
- Do not describe Base64, XOR, compression, or an encoded payload behind an obfuscated loader as full Hercules obfuscation. If Hercules only processes an outer wrapper or fails on the inner code, stop and report this limitation rather than presenting the inner script as obfuscated. Do not silently upload readable or merely encoded source as an obfuscated release.
- Verify the exact artifact to be published, including any nested payload, before upload. Run appropriate Luau syntax and focused behavior checks. Report what was and was not verified, and preserve existing game behavior and user changes.
- Never expose keys, tokens or private URLs in public artifacts, logs or commits. Assume a public raw URL can be accessed and shared without authentication; obfuscation is not access control.
- This policy applies to new publications and updates; it does not assert that existing public files, raw URLs or Git history have become private. Do not delete files, rewrite history, change repository visibility or rotate credentials without the user's instruction.
- Public non-executable assets (such as images) and this policy may be published when requested. Updating a separately maintained, intentionally open-source third-party library requires the user's explicit scope and is not permission to publish Petals Hub's private game-script source.
